# S01 L02 DATA VS. INFORMATION

<p><b>Data vs. Information</b> - The words "data" and "information" are often used as if they are synonyms. Nevertheless, they have different meanings.</p>
<p><b>Data</b> - Raw material from which you can draw conclusions; facts from which you can deduce new facts.</p>
<p><b>Information</b> - knowledge, intelligence, a particular piece of data with a special meaning or function. Information is often the result of combining, comparing, and performing calculations on data. </p>

<p><b>Database</b> - A database is a centralized and structured set of data stored on a computer system.</p>
<ul>
    <li>It provides facilities for retrieving, adding, modifying, and deleting the data when required.</li>
    <li>It also provides facilities for transforming retrieved data into useful information.</li>
    <li>A database is usually managed by a Database Administrator (DBA).</li>
</ul>
